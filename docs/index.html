    Method

    What is being compared

    Two builds of one pinned checkpoint - Xenova/distilbert-base-uncased-finetuned-sst-2-english at revision 0b6928ef: the v1 incumbent is the full-precision (fp16) ONNX build, the v2 candidate is the int8-quantized build of the same weights. Quantization is the canonical silent-regression source: the int8 artifact halves the fp16 build (67 MB vs 134 MB), and the accuracy cost is assumed, rarely proven.

    The golden set

    The validation split of GLUE SST-2: 872 real movie-review sentences with gold sentiment labels - a public benchmark, fixed forever, so any future build can be gated against the identical evidence. Each sentence also carries deterministic capability tags (negation, comparatives, numerals, length bands) assigned by transparent rules, so regressions can be localized rather than averaged away.

    The statistics

    • Paired bootstrap (10,000 resamples, seed 1337): resample sentences with replacement, recompute the accuracy delta each time, take the percentile interval. Pairing on the same sentences is what makes a 1.5-point gap on 872 examples resolvable.
    • McNemar's test (exact two-sided binomial): only the 21 discordant sentences carry signal; 17 flips for the worse against 4 for the better gives p = 0.0072. The chi-square approximation agrees (p = 0.0088).
    • Cohen's h: effect size for two proportions, -0.05 here - small in aggregate, which is exactly why per-slice analysis matters.
    • Fisher exact enrichment: per slice, a one-sided hypergeometric test of whether regressions concentrate there more than the base rate predicts.

    The gate

    ship ⇤ McNemar p ≥ alpha AND CI lower bound ≥ -maxDrop

    Defaults: maxDrop = 0.5 points, alpha = 0.05. The gate is honest both ways - a significant regression holds the build, and an inconclusive comparison says so instead of guessing. Tune it on the Verdict tab.

    Reproduce every number

    node scripts/measure-pair.mjs re-runs both pinned builds over SST-2; node scripts/gen-data.mjs rebuilds the golden set with slice tags; node scripts/compute-snapshot.mjs recomputes every statistic on this page. CI recomputes the snapshot from the committed golden set and fails on any drift.

    Honest limits

    • One model, one task. The method - paired gating on a golden set - is the point, not this particular checkpoint.
    • Slice tags are transparent heuristics, not human annotation; treat per-slice p-values as triage, not verdicts.
    • Browser wasm arithmetic can drift a last-decimal score from the Node pipeline; every reported number comes from the committed Node-measured artifact, not your browser.
